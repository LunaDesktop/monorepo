# Luna — what's new
#
# Format: `## <version> — <date>` starts a release, lines with `- ` are bullets.
# The file can be overridden without rebuilding the app:
#   /usr/share/luna/welcome/news.md
#   ~/.local/share/luna/welcome/news.md
# or point to your own with LUNA_WELCOME_NEWS.
#
# Language variants: news.<lang>.md (e.g. news.en.md) are preferred over
# this file when the session language matches. This file is the Polish one.

## 0.0.8 — 2026-11-05
- Luna Store: installs and updates from pacman, paga, apt, dnf, emerge and Flatpak.
- Luna Clock: world clock, timer, stopwatch and a private, cloud-free calendar.
- Luna Editor and Luna Terminal run entirely on libLuna — no GTK.
- New widgets: Assistant, CodeView, ColumnView, NavigationRail and EmojiChooser.
- Appearance, accent and language settings are shared across the whole session.

## 0.0.7 — 2026-09-18
- Luna Files with a virtualised grid, previews and file operations.
- Luna Media: an image and video viewer that decodes through ffmpeg.
- The Luna panel: notification centre, calendar and app widgets.
